# MoliGod 自动化助手 (DF-AutomatedTool)

一个基于 .NET 8 WPF、OpenCvSharp 和 OnnxRuntime 构建的强大 Windows 桌面自动化工具。

## 简介

本项目旨在提供一个灵活、可视化的 Windows 自动化解决方案。通过集成窗口句柄探测、OCR 文字识别（支持 GPU 加速）以及逻辑控制流（循环、条件判断），用户可以轻松创建复杂的自动化脚本。同时内置**人类化自动购买**模式：让自动化的操作节奏在统计上接近真人。

## 核心功能

*   **窗口探测 (WindowSpy)**
    *   支持拖拽绑定目标窗口句柄。
    *   自动获取窗口标题、类名及位置信息。
*   **可视化自动化步骤**
    *   **鼠标操作**：支持左键/右键点击，支持随机偏移和随机延迟，模拟真实操作。
    *   **键盘输入**：支持发送按键和文本。
    *   **OCR 文字识别**：基于 PaddleOCR 模型 (OnnxRuntime)，支持 DirectML GPU 加速、ROI 缓存。
*   **人类化自动购买（自动购买页）**
    *   弹窗识别 → 人类化反应延迟 → 爆发点击一组（默认 3~5 下）→ 等弹窗消失重新武装。
    *   时序模型：对数正态分布、AR(1) 自相关、会话级漂移、偶发落点抖动、走神扫描间隔。
    *   停止条件：目标点击次数 / 最长运行分钟 / 防卡死右键×10 + F12 急停。
*   **强大的逻辑控制**
    *   **流程控制**：支持 Loop 循环（无限/计数）、Break 跳出。
    *   **条件判断**：支持 If / ElseIf / Else / EndIf 结构。
    *   **表达式引擎**：支持复杂的变量比较（如 `A1 > 100 && B1 == "OK"`）。
    *   **预编译优化**：脚本运行前自动构建跳转表，实现 O(1) 复杂度的逻辑跳转。
*   **安全机制**
    *   防卡死设计：5秒内连续右键10次可强制停止脚本。
    *   线程安全：UI 与执行逻辑分离，保证界面响应。

## 环境要求

*   **操作系统**：Windows 10 / 11 (64-bit)
*   **运行环境**：
    *   [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) 或 Runtime（编译需要 SDK，运行需要 Runtime）。
    *   [Python 3.10+](https://www.python.org/)（OCR 推理后端；若已打包 OCR exe 则不需要）。
*   **Python 依赖**（未打包 OCR exe 时）：
    ```bash
    pip install -r requirements.txt
    ```

## 快速开始（换机开发）

```bash
# 1. 克隆（含约 165MB OCR 模型，开箱即可运行）
git clone git@github.com:pison233/autoclick.git
cd autoclick

# 2. 编译（需 .NET 8 SDK）
dotnet build -c Release

# 3. 运行
#    输出目录 WindowSpy/bin/Release/net8.0-windows/ 下的 exe
#    务必"以管理员身份运行"（程序强制要求，弹 UAC 点允许）
```

OCR 后端两种方式：
* **已打包**：`Scripts/dist/onnx_ocr_cli/onnx_ocr_cli.exe` 存在时自动使用，无需 Python。
* **未打包**：系统安装 Python 3.10+ 并 `pip install -r requirements.txt`。

模型文件位置：`Scripts/onnxocr/models/ppocrv5/`（det.onnx + rec.onnx + ppocrv5_dict.txt），缺了 OCR 无法初始化。

## 自动购买使用

1. **绑定目标窗口**：点顶部圆形图标（绑定A/B），在目标浏览器/游戏窗口上点一下完成绑定。
2. 切到 **"自动购买"** Tab：
   - 目标窗口选 A 或 B（与绑定一致）。
   - **选择弹窗区域**：框出价格弹窗出现的那块固定位置。
   - **选择购买按钮**：点一下购买按钮位置。
   - 填参数：一组点击次数（默认 3~5）、目标点击次数（0=不限）、最长运行分钟（0=不限）。
3. 点 **"开始自动购买"**。运行后自动循环：
   ```
   扫描弹窗区域 → 弹窗出现 → 反应延迟(~0.2-0.5s) → 爆发连点 3~5 下 → 累计计数
   → 弹窗消失重新武装 → 每 2~3 组停顿 3~6s(核查占位) → 达目标/超时/急停停止
   ```
4. 三种停止方式：界面"停止"按钮 / **F12** 热键 / **5秒内右键10次**（防卡死）。
