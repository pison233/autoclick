# autoclick 自动化助手

一个基于 .NET 8 WPF、OpenCvSharp 和 OnnxRuntime 构建的 Windows 桌面自动化工具（上游项目 fork，见文末署名）。

## 简介

可视化的 Windows 自动化方案：窗口句柄绑定、OCR 文字识别（PaddleOCR/ONNX，支持 DirectML GPU 加速）、可视化步骤编排（条件/循环/跳转/表达式）。另内置**人类化「快捷操作」可视化流程构建器**：一排节点（点击 / 检测(if) / 否则 / 结束）从上到下跑、缩进即 if/else、整轮循环；检测支持同一区域多条 且/或 子条件与「测试识别」，每次点击节奏在统计上接近真人。

## 核心功能

*   **窗口探测 (WindowSpy)**：绑定目标窗口句柄（A/B 双窗口），自动获取标题与位置。
*   **可视化步骤编辑器**：鼠标点击/键盘/OCR 识别 + Loop/If/表达式/Goto 逻辑，支持队列保存/加载、定时任务。
*   **人类化「快捷操作」页（可视化流程构建器）**：
    *   节点：点击 / 检测(if) / 否则 / 结束；if/else 缩进表达，整条链每轮自动循环；检测窗口与点击窗口可分离（A/B）。
    *   检测(if) = 一块区域 + 多条 且/或 子条件（出现文字/为空/数字比较/文本匹配）+ 「测试识别」；触发方式可选 每轮判断 或 仅响应变化（防弹窗重复买入）。
    *   时序模型：对数正态分布、AR(1) 自相关、会话级漂移、偶发落点抖动、走神扫描、核查停顿；全部语义参数可在「高级设置」折叠面板调整。
    *   停止条件（多选）：点击数 / 命中数 / 轮数 / 最长运行分钟 / 检测勾"满足即停" / 防卡死右键×10 + F12 急停。
*   **三主块界面**：快捷操作（可视化流程构建器）/ 复杂操作（原版步骤编辑器整套单页收纳）/ 高级设置（时序模式：人类化或精细延迟 + 两套参数 + GPU）。右侧队列随主 Tab 自动切换显示「快捷流程」或「原步骤队列」。
*   **安全机制**：5 秒内右键 10 次强制停止（系统钩子）、F12 全局热键、UI 与执行线程分离。

## 环境要求

*   **操作系统**：Windows 10 / 11 (64-bit)
*   **运行环境**：[.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)（编译需 SDK）/ Runtime；[Python 3.10+](https://www.python.org/)（OCR 后端；已打包 OCR exe 则不需要）。
*   **Python 依赖**（未打包 OCR exe 时）：`pip install -r requirements.txt`

## 快速开始（换机开发）

```bash
git clone git@github.com:pison233/autoclick.git
cd autoclick
dotnet build -c Release          # 需 .NET 8 SDK
# 运行 WindowSpy/bin/Release/net8.0-windows/autoclick.exe（务必管理员运行）
```

OCR 后端两种方式：已打包 `Scripts/dist/onnx_ocr_cli/onnx_ocr_cli.exe`（自动使用，免 Python）；或系统 Python + `pip install -r requirements.txt`。
模型：`Scripts/onnxocr/models/ppocrv5/`（det.onnx + rec.onnx + ppocrv5_dict.txt），缺则 OCR 无法初始化。

## 三个主 Tab 快速上手

顶部只有 **快捷操作 / 复杂操作 / 高级设置** 三个主 Tab，右侧队列会随 Tab 自动切换（快捷操作时是"快捷流程"列表，复杂操作/高级设置时是"原步骤队列"）。

1. **绑定窗口**：点左上图标（绑定A/B）在要操作的窗口上点一下；检测与点击若在两个窗口，就 A、B 各绑一个。
2. 切到 **「快捷操作」** Tab，用上方按钮搭流程：
   - **＋检测(if)** 框一块区域 → 右侧写**子条件**（如 数字 ≥ 15000）→ **测试识别**看 OCR 对不对。
   - **＋点击** 录购买位置（每轮连点可填 3~5）；要分支加 **＋否则 / ＋结束**，要重复加 **＋循环 / ＋循环结束**，要跳走加 **＋跳转**；缩进即 if/else/循环 层级。
   - 触发方式选「符合条件一直触发」或「条件变化才触发」；勾停止条件：命中（买 N 次）/ 轮数 / 分钟，可多选。
   - 时序与 GPU 在 **「高级设置」**：默认人类化时序；想用原版固定延迟就切"精细延迟"（每个点击节点可设 延迟±随机/偏移/停留）。
3. 点 **「开始执行」**。每轮从上到下执行，跑完自动循环；点击带人类化反应/间隔/抖动；达停止条件/急停即停。
4. 停止：界面「停止」/ **F12** / **5 秒内右键 10 次**。可「保存流程」便于换机后带回。
5. 要用原版强大功能（表达式/局部循环/标签跳转/按键/定时任务…）：切到 **「复杂操作」** 页配置，队列在右侧。

原用法与完整实战见 [`USAGE.md`](USAGE.md)。
